# 🚀 Daily LeetCode

Welcome to my **Daily LeetCode Repository**!

This repository contains my solutions to LeetCode problems that I solve every day. My goal is to maintain consistency, improve problem-solving skills, strengthen data structures & algorithms knowledge, and become proficient in multiple programming languages.

## 📌 Rules

- Solve **at least 1 LeetCode problem every day**.
- Solutions may be written in:
  - C
  - Java
  - Python
  - Or any other programming language

- Commit and push the solution daily.
- Organize solutions in separate folders based on the problem name.
- Keep the repository updated consistently.

## 📂 Repository Structure

```text
Leetcode/
├── 1_Two_Sum/
│   └── 1_Two_Sum.c
├── 2_Add_Two_Numbers/

```

Each folder represents a LeetCode problem and contains one or more solution files.
